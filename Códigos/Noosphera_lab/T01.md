### T01 — Identidade sob transformação

### Ortogonalidade da Identidade sob Mutação

  
**Hipótese Lógica:** Uma entidade $K$ possui identidade própria, ortogonal ao conteúdo de sua representação.

A transição `rep(K): R1 → R2` não altera `id(K)`.

#### 1. Notação Lógica (Lógica de Primeira Ordem e Transição de Estado)

$$\forall K \in \mathcal{K}, \forall t_1, t_2 \in T: \Big( rep(K, t_1) = \{R_1\} \land rep(K, t_2) = \{R_2\} \land (R_1 \neq R_2) \Big) \implies id(K, t_1) = id(K, t_2)$$

---


#### 2. Existência Computacional (Type Theory / Semântica Estrutural)

  

Para que o sistema passe no teste às cegas, a existência computacional exige que o objeto na memória não seja um mero alias para os seus dados (evitando o antipadrão `objeto = {"conteudo": ...}`).


Em **Teoria dos Tipos**, a entidade deve ser formulada como um tipo produto (ou registro dependente), onde a assinatura de identidade é imutável:


$$K := \langle i \in \mathcal{I}, \rho \in \mathcal{P}(\mathcal{R}) \rangle$$

A operação de mutação afeta apenas a projeção $\rho$, mantendo a projeção $i$ intacta:

$$\text{update}( \langle i, \{R_1\} \rangle, \{R_2\} ) \to \langle i, \{R_2\} \rangle$$

---
#### Escopo do Teste

- **Hipótese testada:** Toda entidade possui identidade própria; representações podem mudar (R1 → R2) sem alterar essa identidade.
- **Por que testar:** Sem esse teste seria fácil implementar o sistema tratando o conteúdo como a própria identidade (`objeto = {"conteudo": ...}`), colapsando identidade e forma.
- **Resultado esperado:** K manteve sua identidade quando a representação foi transformada — a forma mudou, a identidade não.
-

```python
def test_t01_identidade_sob_transformacao():

	"""
	
	Hipótese T01: Toda entidade K possui identidade própria (id_absoluto),
	
	ortogonal ao conteúdo de sua representação. A transição rep(K): R1 -> R2
	
	não altera id(K).
	
	  
	
	∀K, ∀t1,t2 ∈ T: (rep(K,t1)={R1} ∧ rep(K,t2)={R2} ∧ R1≠R2) ⟹ id(K,t1)=id(K,t2)
	
	"""

	print("\n--- Executando T01: Identidade sob Transformação ---")
	
	grafo = Graph()
	
	K = noo["Entidade_T01"]
	
	  
	
	grafo.add((K, RDF.type, noo.KnowledgeObject))
	
	grafo.add((K, noo.idAbsoluto, Literal("id-t01-fixo")))
	
	  
	
	r1 = noo["R1_Forma_JSON"]
	
	transformar_representacao(grafo, K, r_antiga=None, r_nova=r1)
	
	id_t1 = extrair_identidade(grafo, K)
	
	rep_t1 = obter_representacoes(grafo, K) # obtém rep(K,t1)
	
	  
	
	print(f"rep(K,t1) = {rep_t1}") # deve mostrar {R1_Forma_JSON}
	
	  
	
	print("Mostrando gráfico: K com a representação R1...")
	
	plotar_grafo_rdf(grafo, "T01 [1/2] — K acoplado a R1 (JSON)")
	
	  
	
	r2 = noo["R2_Forma_XML"]
	
	transformar_representacao(grafo, K, r_antiga=r1, r_nova=r2)
	
	id_t2 = extrair_identidade(grafo, K)
	
	rep_t2 = obter_representacoes(grafo, K) # obtém rep(K,t2)
	
	  
	
	print(f"rep(K,t2) = {rep_t2}") # deve mostrar {R2_Forma_XML}
	
	  
	
	print("Mostrando gráfico: K após a transmutação para R2...")
	
	plotar_grafo_rdf(grafo, "T01 [2/2] — K transmutado para R2 (XML)")
	
	  
	
	assert id_t1 == id_t2, f"FALHA: id(K,t1)={id_t1!r} != id(K,t2)={id_t2!r}."
	
	assert rep_t1 == {r1}, f"FALHA: rep(K,t1) inesperado: {rep_t1}"
	
	assert rep_t2 == {r2}, f"FALHA: rep(K,t2) inesperado: {rep_t2}"
	
	assert r1 not in rep_t2, "FALHA: R1 ainda presente após transformação."
	
	assert r2 in rep_t2, "FALHA: R2 não encontrada após transformação."
	
	  
	
	print(f"Resultado T01: id(K,t1)={id_t1!r} == id(K,t2)={id_t2!r}. ")
	
	print("Identidade preservada sob transformação de representação (R1→R2). ✅")
	
	  
	  
	
test_t01_identidade_sob_transformacao()
```
