# 💻 Funcionalismo Computacional (Teoria Computacional da Mente)

O **Funcionalismo Computacional** postula que a mente humana é um **sistema de processamento de símbolos**, funcionando analogamente a um computador digital. Estados mentais são estados funcionais/computacionais de um organismo ou sistema artificial.

## 🔌 A Analogia Exata: Software e Hardware

O funcionalismo resolve o problema mente-corpo dividindo o sistema humano em duas camadas tecnológicas claras:

| Componente Humano | Componente Computacional | Definição Ontológica |
| :--- | :--- | :--- |
| **Cérebro (Sistema Nervoso)** | **Hardware (Circuitos de Silício)** | O substrato físico que fornece o suporte de energia e execução. |
| **Mente (Estados Mentais)** | **Software (Algoritmos / Código)** | O conjunto de regras e instruções lógicas que processam dados. |

*   **Conclusão:** A mente não é uma substância fantasmagórica (Descartes) nem um pedaço de carne química (Smart); a mente é a **organização funcional** do cérebro.

## ⚙️ A Mente como uma Máquina de Turing
Putnam argumentou que os estados mentais humanos funcionam como os estados lógicos de uma **Máquina de Turing**:
*   A mente recebe um input (um estímulo sensorial do mundo exterior ou um dado de entrada no sistema).
*   A mente consulta sua tabela de estados internos (regras de inferência, ontologias, memórias).
*   A mente altera seu estado interno e gera um output (um comportamento físico ou uma nova gravação no banco de dados).

```

[ Input Sensorial / Dados ] ──> ( Estado Funcional Interno ) ──> [ Output / Comportamento ]  
│  
▼  
( Consulta à Ontologia/Regras )

```

## 🧠 A Teoria Representacional da Mente (Jerry Fodor)
Para que o funcionalismo funcione em sistemas de conhecimento, Jerry Fodor propôs a hipótese do **Linguajar do Pensamento (Mentalez)**:
*   Pensar é manipular símbolos físicos de acordo com regras sintáticas.
*   A mente possui uma gramática interna que permite combinar conceitos complexos a partir de conceitos atômicos.
*   **Conexão Semiótica:** Isso gerou diretamente a engenharia de conhecimento moderna. As triplas RDF e linguagens de ontologia (OWL) são tentativas diretas de externalizar essa estrutura funcional em software.

## 🚧 Limites do Paradigma (Aviso para Sistemas Complexos)
Embora excelente para modelagem conceitual, o funcionalismo computacional enfrenta críticas severas na filosofia da mente contemporânea:
1. **[[O Quarto de Mary]] (Problema dos Qualia):** Computadores processam a sintaxe, mas não possuem a experiência subjetiva (a sensação de ver a cor vermelha).
2. **[[O Argumento do Quarto Chinês de Searle]]:** A manipulação puramente sintática de símbolos não gera semântica de verdade. O sistema simula a compreensão, mas não entende o significado real dos dados.
